# proud-vale-cli



给自己省点事的小工具

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/proud-vale-cli.git
cd proud-vale-cli
chmod +x run.sh
```
